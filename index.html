Results by Type — project detail and output links

OSCARS · 70 funded projects · 432 outputs recorded, 346 with a link · 12 output types · updated 12 October 2026 · source: OSCARS funded projects database and D4.4 Impact Report
Each output is shown with its real title, coloured to match its output type, and — where the source says more than the title alone — a short description of what it is. The type is what the output is; the link or DOI only says where it lives, so a GitHub link or a Zenodo DOI does not decide the type. Each output is listed once, under the one type it matches; the only exception is flagged where it occurs. When a project has an output declared in its own results but no link yet, the description is shown instead, marked “no link yet”. Below each project title, tags show which other types it also appears in — click one to jump to that section. A filled tag means the project has a linked output of that type; an outlined tag means it is declared with no link yet. Every project also links to its page on the OSCARS website.

What counts as what — the 12 output types

Software & ToolsSoftware applications, libraries, command-line tools, AI/ML models, scripts, notebooks, software releases.
Datasets & DatabasesDatasets, curated data collections, catalogues and databases: the data itself.
Platforms & PortalsWeb platforms, portals, dashboards and other online services with a user interface.
Ontologies & StandardsOntologies, controlled vocabularies, taxonomies, metadata schemas, mappings, data-format standards.
Workflows & PipelinesData-processing pipelines, computational workflows and documented protocols of processing steps.
RepositoriesRepositories and collections the project created as a place to deposit and share outputs (e.g. a Zenodo community, a Dataverse collection, a data repository). Not any link that happens to point to a repository.
Infrastructure & ServicesPhysical or operational infrastructure and services set up or upgraded: stations, labs, VREs, deployed service instances.
Technical DocumentationUser guides, manuals, technical and API documentation of a tool or platform, with or without DOI.
Reports & PlansData management plans, requirements and gap/landscape analyses, deliverables, reports, protocols, plans, white papers and policy briefs, with or without DOI.
Presentations & Training ResourcesReusable learning and presentation material (slides, recordings, webinar replays, videos, tutorials, textbooks, guides, course material) and training activities organised by the project (workshops, webinars, schools, bootcamps, hackathons). Training activities the projects organised or took part in (workshops, schools, hackathons, webinars) are listed here too, marked “training activity”; all other events are counted separately, in the Events card, and not as outputs.
PublicationsScholarly publications: journal articles, conference papers and proceedings, preprints, books and chapters. Two items are also listed under a second type: a data descriptor article (also a dataset) and a benchmark report (also technical documentation).
PostersConference and event posters.
